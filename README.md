# INTIMO.com.ua — 1:1 Клон интернет-магазина (Railway Ready)

Полнофункциональный клон интернет-магазина нижнего белья и купальников [intimo.com.ua](https://www.intimo.com.ua), адаптированный для развертывания на облачной платформе **Railway** и локального запуска на **Node.js**.

---

## ✨ Возможности проекта

1. **Дизайн и верстка 1 в 1**:
   - Оригинальная палитра цветов (#be2c4b, #3b243a, #fcf7f7), оригинальная типографика и стили.
   - Хедер с телефонами, шоурумом, переключателем языков и кнопкой заказа звонка.
   - Промо-полоса скидок и слайдер акций («SALE до -60%»).
   - Главная навигационная панель с разделами каталога (Женщинам, Мужчинам, Детям, Бренды, Скидки).
   - Интерактивные карточки товаров с переключением фото при наведении, бейджами скидок, размерами, ценами в гривнах (₴).
   - Табы на главной («Хиты продаж», «Новинки 2026», «Акции и скидки»).
   - Преимущества магазина (бесплатная доставка, примерка перед покупкой, 100% оригинал, обмен 14 дней).
   - Футер с подробной информацией о компании, подпиской на рассылку и иконками платежных систем.

2. **Интерактивный функционал**:
   - 🛒 **Корзина покупок**: выдвижная шторка (Drawer), подсчет общей суммы, изменение количества, удаление товаров, сохранение в `localStorage`.
   - 🔍 **Живой поиск**: мгновенный поиск товаров на лету по названиям, брендам и категориям с выпадающим списком превью.
   - ⚡ **Быстрый заказ ("Купить в 1 клик")**: модальное окно с вводом номера телефона и отправкой заказа на бэкенд.
   - 📞 **Заказ звонка**: модальное окно обратной связи.
   - ❤️ **Избранное (Wishlist)**: добавление в избранное с пересчетом счетчика.
   - 📱 **Адаптивность**: полноценное отображение на смартфонах и планшетах.

3. **Бэкенд и REST API**:
   - `GET /health` — healthcheck для Railway (проверка статуса сервиса).
   - `GET /api/products` — каталог товаров с поддержкой фильтрации по категориям, ценам, скидкам и сортировкой.
   - `GET /api/products/:id` — данные отдельного товара.
   - `GET /api/search?q=...` — полнотекстовый поиск.
   - `POST /api/order` — обработка и регистрация заказов.

## 🚀 Быстрый запуск локально

### Требования
- Node.js 18+
- npm

### Установка и старт
```bash
# 1. Установка зависимостей
npm install

# 2. Запуск сервера
npm start
```
Сервер будет доступен по адресу: [http://localhost:3000](http://localhost:3000)

## 🚂 Развертывание на Railway

Проект полностью настроен для хостинга на [Railway](https://railway.app):
- Включен файл `railway.json` с конфигурацией Nixpacks и `healthcheckPath: /health`.
- Добавлен `Dockerfile` (Node.js 20 Alpine) для сборки контейнера.
- Добавлен `Procfile` (`web: npm start`).
- Сервер автоматически слушает порт из переменной окружения `process.env.PORT` на хосте `0.0.0.0`.

### Способ 1: Деплой через GitHub (Рекомендуемый)
1. Зайдите в панель [Railway.app](https://railway.app).
2. Нажмите **"New Project"** -> **"Deploy from GitHub repo"**.
3. Выберите репозиторий `martatango606-sketch/samsunggalaxya23`.
4. Railway автоматически обнаружит Node.js проект, соберет его и выдаст публичный URL (например: `https://...up.railway.app`).

### Способ 2: Деплой через Railway CLI
```bash
npm i -g @railway/cli
railway login
railway init
railway up
```
